# Elementary

**Elementary** is a chemistry learning web app, currently under development. The goal is to make learning chemistry simple and interactive, starting with the periodic table and expanding to more advanced topics.

## Features

- Interactive learning cards with multiple-choice questions.
- Progressive learning levels.
- Randomized questions covering chemical elements, symbols, atomic numbers, groups, and categories.
- Learning session results and accuracy tracking.
- Guest learning without mandatory registration.
- User registration to track learning progress.

## Tech Stack

- Angular, TypeScript 
- Python, FastAPI 
- PostgreSQL 
- SQLAlchemy 
- Alembic 
- Pydantic 
- Auth0
